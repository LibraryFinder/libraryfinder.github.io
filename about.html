📖 О продукте

LibraryFinder — интерактивный гид по популярным библиотекам Python.

Что это

Проект помогает быстро находить подходящую библиотеку для решения задачи. Всё собрано в одном месте: от численных расчётов и визуализации до веб-разработки, ИИ, баз данных и автоматизации.

Установка библиотек

Почти все библиотеки Python устанавливаются через pip — менеджер пакетов Python. Установка обычно занимает одну команду в терминале и не требует других настроек.

Базовый pip

Установите библиотеку командой:

pip install имя-библиотеки

Виртуальное окружение

Рекомендуется ставить библиотеки в виртуальное окружение, чтобы изолировать зависимости проекта. Создаётся командой:

python -m venv .venv

Файл requirements.txt

Для воспроизводимости проекта список библиотек сохраняют в файле requirements.txt и устанавливают разом:

pip install -r requirements.txt

Встроенные модули (например, os, sqlite3) устанавливать не нужно — они уже входят в Python. Конкретные команды установки для каждой библиотеки приведены в официальной документации.

Категории

В каталоге собрано более 40 библиотек Python — от классических NumPy, Pandas и Flask до современных Polars, Hugging Face и Kubernetes.
